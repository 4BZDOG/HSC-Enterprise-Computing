A

Absolute Reference

A spreadsheet cell reference, written with dollar signs such as $H$1, that does not change when the formula is copied or filled.

Example: =D2*$H$1 keeps pointing at the GST rate cell.

Abstraction

NESA

The process by which data and programs are defined with a representation similar in form to its meaning while hiding away the implementation details. Abstraction tries to temporarily ignore details so that the programmer can focus on a few concepts at a time. Algorithms must ultimately be broken down into simple instructions for a digital system to execute.

Example: A train map shows stations and lines but hides the real curves of the track.

See also: Computational Thinking

Acceptance Testing

Testing in which the client or users check the finished system against agreed criteria to decide whether to accept it.

Example: The canteen manager completes her daily tasks and signs off.

See also: Beta Testing

Action Plan

A short-range list of tasks with an owner, a due date and a status, usually drawn from a Gantt chart.

Example: A weekly table of who builds the Menu tables and by which day.

Actuator

A device that converts a control signal into a physical action, such as opening a valve or switching a relay.

Example: A vent actuator that opens when a greenhouse is too hot.

See also: Sensor

Adaptive Maintenance

Maintenance that changes a system to suit a change in its environment or requirements.

Example: Adding a new menu item or updating prices when the menu changes.

Adjacency Matrix

A grid that records which nodes in a graph are directly linked, using 1 (or a weight) for a link and 0 for none.

Example: Row A of a friendship matrix reads 0 1 1 1 0 0, so A is linked to B, C and D.

See also: Node

Aggregation

Combining many records into a summary such as a total, average or count for each group.

Example: Total takings for each month.

Agile Approach

A development approach that builds the system in short cycles, each producing working output that the client reviews before the next cycle is planned.

Example: A club booking app delivered in two-week sprints, with the club secretary reviewing each one.

See also: Product Backlog, Sprint, Waterfall Approach

Air Gap

Keeping a system physically or logically disconnected from other networks so it cannot be reached across them.

Example: An offline backup server that is never connected to the office network.

See also: Firewall

Algorithm

NESA

A step-by-step procedure required to solve a problem. Algorithms may be presented in many ways, e.g. written instructions, flow charts or using a computer programming language.

Example: The steps a canteen app follows to total an order: add each price, apply the discount, then add GST.

Alternative Data

Data from non-traditional sources, such as likes, emoticons and memes, used as quick feedback about a product or message.

Example: A surge of angry-face reactions on a post about a new e-bike.

App

NESA

A software program designed for a specific purpose to run on mobile devices or on a personal computer. An abbreviation of the word ‘application’.

Example: A school canteen ordering app on a phone.

Artificial Intelligence (AI)

NESA

Intelligence demonstrated by machines. Sometimes called machine intelligence.

Example: A spam filter that learns to recognise junk email.

Assets

NESA

Assets are the digital elements that can be used or incorporated into a multimedia presentation or production. They include graphics, photographs, videos, audio, animations or other artistic data.

Example: A logo in SVG, a photo in JPEG and an interview in MP4 used on one website.

Attenuation

The weakening of a signal as it travels through a medium or across distance.

Example: An Ethernet cable run beyond about 100 m loses too much signal to work reliably.

Augmented Reality (AR)

NESA

A technology that replicates, enhances or overlays extra information about the real-world environment, using computer-generated data such as global positioning systems (GPS), sound, videos and images. Common examples include a car windshield with a heads-up display (HUD) that projects three-dimensional navigation information and virtual lanes, or a swimming telecast using a line to indicate the position of the record holder in relation to the actual swimmers in the race.

Example: A phone app that shows how a sofa would look in your lounge room through the camera.

See also: Virtual Reality (VR)

Auto-profiling

The automatic building of a picture of a person by inferring interests and characteristics from their behaviour without them entering it.

Example: A video app recommending content based on what you watched, not on what you said you liked.

Automate

NESA

The process of transforming and manipulating data that does not require user intervention. For example, through the use of formulae in a spreadsheet, new sets of data can be processed and the results recalculated automatically, or a webcam can be turned on as a result of movement sensor input.

Example: A spreadsheet total that recalculates by itself whenever a price is changed.

B

Backup Rule (3-2-1)

A backup guideline of keeping three copies of data on two types of media, with one copy offsite.

Example: Live data on a server, a copy on a storage device, and a copy on tape at another site.

Backward Chaining

NESA

A technique used by inference engines that determines reasoning from the knowledge base to understand how a decision was made. In backward chaining, the goal or output is used to track back to establish the steps taken.

Example: To prove repot_with_drainage, the engine checks root_rot_risk, then overwatered, then the observed facts.

See also: Forward Chaining

Bandwidth

The maximum amount of data a connection can carry per second, usually measured in megabits per second.

Example: A 100 Mbps nbn plan can carry up to 100 megabits each second.

See also: Latency, Quality of Service (QoS)

Beta Testing

Testing a near-final version of a system with a limited group of real users outside the development team to find remaining faults.

Example: Fifty students trial a new school app for a fortnight.

See also: Acceptance Testing

Betweenness Centrality

A measure of how often a node lies on the shortest paths between other pairs of nodes, showing which nodes act as bridges.

Example: A switch that joins two office floors carries most cross-floor traffic, so it has high betweenness.

See also: Degree Centrality

Big Data

NESA

Extremely large datasets that may be analysed computationally to reveal patterns, trends and associations.

Example: A GPS point logged every few seconds for every bike in a scheme.

See also: Data Mining

Biometric

NESA

A term that describes the source of data being human or biological.

Example: A fingerprint or face scan used to unlock a phone.

Bit Depth

The number of bits used to record each sample or pixel, which sets how many different values can be stored.

Example: 16-bit audio allows 65,536 possible heights per sample; 24-bit colour allows about 16.7 million colours.

Bitmap Graphic

An image made from a grid of pixels, each with its own colour, so it blurs or pixelates when enlarged.

Example: A photograph saved as a JPEG or a screenshot saved as a PNG.

See also: Vector Graphic

Blockchain

NESA

A growing list of records, known as blocks, which are linked using cryptography. It can be used to record transactions between 2 parties efficiently and in a verifiable and permanent way.

Example: Each block stores the hash of the previous block, so editing one block breaks every later link.

See also: Distributed Ledger, Hash Function

Botnet

A network of infected devices (bots) controlled remotely by an attacker, often to run a DDoS attack or send spam.

Example: Thousands of infected home routers flood a website with requests at once.

See also: Ransomware

Boundary Test Data

Test values that lie on the limit of an allowed range and immediately either side of it.

Example: For a booking length of 30 to 120 minutes, the boundary values are 29, 30, 120 and 121.

See also: Erroneous Test Data

Business Email Compromise

A scam that takes over or imitates a business email account to trick staff into sending payments or data to a criminal.

Example: An email that appears to be from a supplier asks for a payment to a new bank account.

See also: Social Engineering

C

Calculate

NESA

Ascertain/determine from given facts, figures or information.

Example: Calculate the total cost of 12 items at $4.50 each, including 10% GST.

CAPTCHA

NESA

Completely Automatic Public Turing Test to Tell Computers and Humans Apart.

Example: A sign-up form that asks you to pick every image containing a bus before it lets you continue.

CARE Principles

Principles for Indigenous data governance from the Global Indigenous Data Alliance: Collective benefit, Authority to control, Responsibility and Ethics.

Example: A research team agrees with an Aboriginal community-controlled organisation how its data will be stored and shared.

See also: Data Sovereignty

Certainty Factor (CF)

A number, here from 0 to 1, that shows how strongly a piece of evidence or a rule is believed.

Example: A rule with CF 0.8 and evidence with CF 0.7 gives a conclusion with CF 0.56.

See also: Fuzzy Logic

Change Request

A formal request to alter something already agreed, assessed for its effect on cost, time and scope before it is accepted.

Example: The committee asks for a waiting list and the team costs it before agreeing to add it.

Cherry-picking

Choosing only the data, date range or results that support a preferred conclusion.

Example: Showing July to December sales growth and hiding the January to June decline.

CIA Triad

The three attributes of information security: confidentiality, integrity and availability.

Example: Ransomware that locks files breaches availability; a leaked database breaches confidentiality.

Clarify

NESA

Make clear or plain.

Example: Clarify the client’s need by asking what "faster booking" means: fewer clicks or a quicker page load.

Classify

NESA

Arrange or include in classes/categories.

Example: Classify survey answers as quantitative (a rating out of 5) or qualitative (a written comment).

Cloud Computing

NESA

Distributing computing over a network where storage of files, processing of data and/or access to software occurs automatically on interconnected server computers to which the user’s device is connected. The term refers to accessing files, software and services over the internet.

Example: A small business keeps its files in a cloud drive and pays each month for exactly the storage it uses.

See also: Edge Computing, Hybrid Cloud, Infrastructure as a Service (IaaS), Platform as a Service (PaaS), Software as a Service (SaaS)

Collaborate

NESA

Working with others towards a shared goal, through a variety of modes of communication. This may be achieved using a range of technologies, tools and processes.

Example: A project team edits one shared design document and agrees decisions in a weekly meeting.

Computational Thinking

NESA

A process in which a problem is analysed and solved so that a human, machine or computer can effectively implement the solution. It involves using strategies to organise data logically, break down problems into parts, interpret patterns and design, and implement algorithms to solve problems.

Example: Breaking "run the school canteen online" into ordering, paying and preparing, then solving each part separately.

See also: Abstraction

Conditional Formatting

A spreadsheet feature that changes how a cell looks automatically when its value meets a rule.

Example: Shading a stock cell red when it falls below 10.

Connectedness

The property of a graph in which there is a path between every pair of nodes; a graph that is not connected splits into separate components.

Example: Cutting the only cable to a building leaves the network disconnected.

Consensus Mechanism

The rule a distributed network uses to agree on which new block or record is valid.

Example: Proof of work and proof of stake are two consensus mechanisms.

See also: Distributed Ledger

Constraint

A limit on a project, such as time, money, skills or equipment, that the team must work within.

Example: A six-week deadline and no budget for software.

Contingency

An amount of money or time set aside in a plan to cover problems that could not be foreseen.

Example: A budget of $690 adds a 10% contingency of $69.

Cookie

A small piece of data a website stores in the browser to keep a session, remember preferences or track activity.

Example: A shopping cart that remembers items after you close the tab.

See also: Digital Footprint

Copyright

The legal right of a creator to control how their original work, such as text, images, music, video and software, is copied, shared and adapted. In Australia it arises automatically under the Copyright Act 1968.

Example: Reusing a photo from a website only if its licence allows, and acknowledging the creator.

See also: Creative Commons, Indigenous Cultural and Intellectual Property (ICIP)

Corrective Maintenance

Maintenance that finds and fixes faults reported after a system has been put into use.

Example: Fixing an import that fails when an item name has a trailing space.

Creative Commons

NESA

Is a non-profit organisation that enables the sharing of creative content without the need to seek legal approval.

Example: A photo licensed CC BY 4.0 that you can reuse if you credit the creator.

See also: Copyright

Credential Stuffing

An attack that automatically tries username and password pairs leaked from one breach on other sites, relying on password reuse.

Example: Stolen email and password pairs are tested against a streaming service login.

See also: Multi-Factor Authentication

Critical Path

The longest chain of dependent tasks in a project plan, which decides the earliest finish date; a delay to any task on it delays the whole project.

Example: If the database build slips a day, the dependent screens, integration and testing all move back a day.

See also: Gantt Chart, Task Float

Critically Analyse/Evaluate

NESA

Add a degree or level of accuracy, depth, knowledge and understanding, logic, questioning, reflection and quality to (analyse/evaluate).

Example: Weigh the strengths and weaknesses of a solution against its success criteria, question the evidence and reach a justified conclusion.

Crowdsourcing

Using a large group of people, usually online, to contribute information, ideas or work.

Example: Residents reporting flood levels through a community social media page.

Cyber Safety

NESA

A term that refers to behaviour and the precautions that may be exercised when providing personal information in an online or digital environment.

Example: Keeping your address and birth date private on a public profile.

Cybersecurity

NESA

The protection of information technology elements, including hardware and software, data or network services.

Example: A business patches its software, backs up its data and uses multi-factor authentication.

D

Dark Pattern

A deceptive design technique that steers users into choices that are not in their interest.

Example: A cancel link hidden behind five clicks while sign-up takes one.

Dashboard

A single screen that brings together the key figures, charts and controls someone needs to monitor a system or make a decision.

Example: Canteen Insights shows revenue, items sold, top seller and waste, with a line chart, a bar chart and a reorder list on one page.

Data

NESA

A discrete representation of information using number codes. Data may include characters (e.g. alphabetic letters, numbers and symbols), images, sounds and/or instructions that, when represented by number codes, can be manipulated, stored and communicated by digital systems. For example, characters may be represented using ASCII code or images may be represented by a bitmap of numbers representing each ‘dot’ or pixel.

Example: The letter A stored as the number 65 in ASCII, or a photo stored as a grid of pixel colour numbers.

See also: Dataset, Information

Data Bias

A systematic tilt in how data is collected, analysed or used, so that results consistently lean in one direction.

Example: Surveying only app users, so riders without smartphones are missing from the results.

Data Compression

NESA

A reduction in the number of bits needed to represent data.

Example: Saving a photo as a JPEG so it downloads faster.

See also: Lossless Compression, Lossy Compression

Data Cube

A multidimensional arrangement of data in which each cell holds a measure at the intersection of several dimensions.

Example: A cube of sales with Product, Quarter and Region as its three dimensions.

See also: Dice, Dimension, Measure, OLAP (Online Analytical Processing), Slice

Data Dictionary

A comprehensive description of each field in a database, commonly listing the field name, data type, data format, field size, description and an example.

Example: UserID: Text, XXXNNNN, size 7, example XYZ1539.

Data Flow Diagram (DFD)

A diagram that shows how data moves between external entities, processes and data stores, using circles for processes, open-ended rectangles for data stores, closed rectangles for external entities and labelled curved arrows for data flows.

Example: A voting system DFD showing Voters sending their details and vote to the Voting process.

See also: Data Store, External Entity, Level 0 Data Flow Diagram

Data Integrity

The accuracy, completeness, consistency and trustworthiness of data across its whole life.

Example: Validation checks and access controls that stop a price of 5500 replacing 55.00.

See also: Validation

Data Journalism

Finding, analysing and presenting data to tell a news story, often using interactive charts or maps.

Example: An interactive map letting readers look up rainfall in their own town.

Data Literacy

The ability to read, understand, question and communicate with data.

Example: Checking who collected a chart's data, how big the sample was and whether the axis starts at zero.

Data Minimisation

The principle of collecting and keeping only the personal information that is needed for a stated purpose.

Example: A quiz app that asks only for an email address, not a birth date.

Data Mining

Discovering patterns, relationships and unusual values in large datasets using statistics and machine learning.

Example: Finding groups of riders with similar travel habits so that passes can be designed for each.

See also: Big Data

Data Retention

The rule for how long data are kept before they are deleted or summarised.

Example: Keeping item-level sales rows for 12 months, then reducing them to weekly totals.

Data Sampling

NESA

The practice of analysing a subset of a larger dataset in order to determine meaningful information such as patterns and trends.

Example: Surveying 200 students to learn about the habits of a school of 1,200.

See also: Stratified Sampling

Data Sovereignty

NESA

This is a global movement that refers to the right of Indigenous Peoples to determine the creation, collection, ownership and application of data that is for and about Indigenous Peoples. The term also refers to transnational data flow and a range of issues arising from the flow of data between nations.

Example: An Aboriginal community-controlled organisation decides how data about its community is collected, stored and used; a business chooses an Australian cloud region so customer records stay under Australian law.

See also: CARE Principles, Indigenous Cultural and Intellectual Property (ICIP)

Data Store

A place where data is kept between processes, either an electronic file or non-computer storage; drawn as a rectangle open on one side in a DFD.

Example: An Electoral roll in a voting system.

See also: Data Flow Diagram (DFD)

Data Swamp

A data lake that has become unusable because nothing records what the data is, where it came from, its quality or who owns it.

Example: A store of thousands of unlabelled, duplicate files that analysts cannot trust.

Data Types

NESA

Data types used in computing are expressed as either: string/text, character, integer, floating point or real, date and time or Boolean.

Example: A price is a floating point number, a quantity is an integer and a booking date is date and time.

Data Warehouse

A large central store of consistent, historical data from many operational systems, organised for analysis and reporting.

Example: A retailer loads nightly sales from 90 stores into one warehouse and compares years.

See also: ETL (Extract, Transform, Load), OLAP (Online Analytical Processing)

Database

NESA

A collection of data organised by records and fields that can be easily stored, accessed, managed and updated.

Example: A canteen keeps its items, prices and orders in tables of records and fields.

See also: Flat-File Database, Relational Database

Dataset

NESA

A collection of data combined for a specific purpose.

Example: A year of bike-share trips gathered to study which stations are busiest.

See also: Data

Days of Stock

The number of trading days the stock on hand will last at the current average rate of sales, found by dividing stock on hand by average daily sales.

Example: 58 bottles on hand and 36 sold a day gives about 1.6 days of stock.

Decision Support System (DSS)

An information system that combines data, a model and an interface to help people make decisions, without making them alone.

Example: A supermarket tool that forecasts demand and suggests next week's order for a manager to adjust.

Decision Tree

A diagram that represents all possible combinations of decisions and their resulting actions, where each path leads to another decision or a final action.

Example: A tree that decides whether to buy a car from its mileage, type and colour.

Deepfake

Synthetic audio, image or video created with artificial intelligence to imitate a real person.

Example: A cloned voice of a manager asking for an urgent payment.

Degree Centrality

A measure of a node's importance based on the number of edges connected to it.

Example: A user with 3 friends in a six-person network has degree 3 and normalised degree centrality 3 ÷ 5 = 0.6.

See also: Betweenness Centrality

Deliverable

A specific item that a project must produce and hand over, such as a working system, a user guide or a test report.

Example: The user guide handed to the canteen manager.

Design Thinking

NESA

A process where a need or opportunity is identified and a design solution is developed. The consideration of economic, environmental and social impacts that result from designed solutions are core to design thinking. Design thinking methods can be used when trying to understand a problem, generate ideas and refine a design based on evaluation and testing.

Example: Interviewing students about lunch queues, then testing a paper prototype of an ordering site.

See also: Prototype

Dice

An OLAP operation that selects a sub-cube by choosing values on two or more dimensions.

Example: Dicing for Coffee and Cake in Q3 and Q4 across both regions.

See also: Data Cube, Slice

Digital Citizenship

NESA

An acceptance and upholding of the norms of appropriate, responsible behaviour with regard to the use of digital technologies.

Example: Checking a claim before sharing it and asking permission before posting a photo of a friend.

Digital Footprint

NESA

Traces of data left behind by a person using a digital system. A person’s digital footprint includes all information actively provided by that person, such as interactions on social networks, online purchases, emails and instant messages. It also includes passive information, such as logs of software installed and used on a computer, metadata associated with files, a user’s internet protocol (IP) address, a device being used to access a webpage, and a user’s browsing history stored as cookies or by internet service providers.

Example: Posts you share (active) and your IP address in server logs (passive).

See also: Cookie, Metadata

Digital Technologies

NESA

Refers to electronic tools, systems, devices and resources that generate, process or store data, and may include applications, games, microcontrollers, mobile devices, multimedia, networks, robotics.

Example: A tablet, a robot vacuum, a school network and a game console.

See also: Hardware

Digital Twin

A virtual copy of a physical machine, building or process that is updated with live sensor data and used to test changes and predict faults.

Example: A model of a pump that shows when its vibration pattern suggests a failure.

Dimension

A category by which data is viewed and grouped in analysis, often with a hierarchy of levels.

Example: Time is a dimension with the levels year, quarter, month and day.

See also: Data Cube

Disruptive Technology

A technology that changes how people or organisations do something so much that established products, services or business models are displaced.

Example: Streaming services displaced most DVD rental shops.

Distributed Ledger

A record of transactions held as identical copies on many computers (nodes), with no single master copy.

Example: Every node in a public blockchain stores the full chain of blocks.

See also: Blockchain, Consensus Mechanism

Drill-down

Moving down a hierarchy to see more detailed data.

Example: Going from quarterly sales to the three months in that quarter.

See also: Roll-up

E

Edge

A line in a graph that joins two nodes and may carry a label or a weight. Also called a link.

Example: A friendship between two users, or a cable of 25 m between two buildings.

See also: Node

Edge Computing

NESA

A computing framework that allows for the distribution of processing capabilities and hardware so that applications can be closer to their data source.

Example: A gateway on a farm that decides when to switch a pump on without waiting for the cloud.

See also: Cloud Computing, Internet of Things (IoT)

Encryption

NESA

A process in cryptography of encoding (converting) data, using mathematical formulas, into a form that only an intended recipient can decode, often including a personal digital signature.

Example: A messaging app scrambles each message so that only the recipient’s device can read it.

See also: Hash Function

End-User Development

A development approach in which the people who will use the system build or adapt it themselves, usually with accessible tools such as spreadsheets or no-code software.

Example: A club secretary builds a membership tracker in a spreadsheet.

Enterprise

NESA

An activity that produces goods and/or services. Enterprises are run for the benefit of an individual or a group of individuals. They can range in scale from a transnational corporation to home-based economic activities.

Example: A local bakery that takes online orders and tracks its stock in a spreadsheet.

See also: Enterprise Computing, Enterprise System

Enterprise Computing

NESA

Refers to business-oriented information technology that is critical to a company’s operations. Enterprise computing encompasses types of information technology tools that businesses use for resource management, efficient production operations, relationship management and back office support.

Example: A retailer’s stock control, sales reporting and customer database working together.

See also: Enterprise

Enterprise System

NESA

The combination of digital systems, people and processes that collect, manage and analyse data.

Example: A club’s booking system: staff and members (people), a booking process, and a database that stores and reports on bookings.

See also: Enterprise, Information System

Erroneous Test Data

Test data that the system should reject, such as data of the wrong type, an impossible value or a missing entry.

Example: Entering "abc" or leaving a blank for a booking length.

See also: Boundary Test Data

Essential Eight

A set of eight mitigation strategies published by the Australian Signals Directorate, with maturity levels, to help organisations defend against cyber threats.

Example: Multi-factor authentication and regular backups are two of the eight.

ETL (Extract, Transform, Load)

The process of copying data from source systems, converting it to consistent formats and definitions, and loading it into a data warehouse.

Example: Matching old and new product codes before loading sales history.

See also: Data Warehouse

Evaluate

NESA

Make a judgement based on criteria; determine the value of.

Example: Judge whether a new booking system met its success criteria, using test results and user feedback.

Evil Twin

A rogue Wi-Fi access point that copies a legitimate network's name so nearby devices connect to it and their traffic can be intercepted.

Example: An attacker broadcasts 'Cafe_Free_WiFi' next to a real cafe network.

Expert System

A program that captures the knowledge of human experts as facts and IF–THEN rules and uses an inference engine to reach conclusions about a narrow topic.

Example: A help-desk system that diagnoses a printer fault from the lights a user reports.

See also: Explanation Facility, Inference Engine, Knowledge Base

Explanation Facility

A feature of an expert system that shows why a question was asked or how a conclusion was reached, usually by displaying the rules used.

Example: A tree showing that reduce_watering came from rule R5, which used overwatered, which came from rule R1.

See also: Expert System

External Entity

A person, organisation or element outside a system that provides data to it or receives data from it.

Example: Students who place orders in a canteen ordering system.

See also: Data Flow Diagram (DFD)

Extrapolation

Extending a pattern beyond the range of the data used to find it, which makes predictions less reliable.

Example: Using a trend line built on 21 to 35°C data to predict boardings at 42°C.

F

Feasibility Study

An assessment, made before a project is committed to, of whether it can succeed: technically, economically, operationally, on schedule and legally.

Example: A team checks that the planned cost is within budget and that volunteers can be trained before starting the build.

See also: Success Criteria

Firewall

Hardware or software that filters network traffic against a set of rules, allowing or blocking it.

Example: A firewall that denies all traffic from guest Wi-Fi to the staff network.

See also: Air Gap

Firmware

NESA

Is the software that is installed on a small chip in almost all hardware devices that makes the hardware function as the manufacturer intended it to.

Example: The software on a home router that manufacturers update to fix security faults.

Flat-File Database

A database that stores all its data in a single table of records and fields.

Example: A single table of trips that repeats each rider's name on every row.

See also: Database, Relational Database

Foreign Key

A field in one table that holds the primary key value of a record in another table, creating a link between the tables.

Example: Publisher_ID in the Games table.

See also: Primary Key, Relational Database, Schema

Forward Chaining

NESA

A technique used by inference engines that applies reasoning to the knowledge base to get the information to make a decision. In forward chaining, the inference engine evaluates existing data to develop new data to make a decision.

Example: Starting from leaves_yellow and soil_wet, an engine adds overwatered and then reduce_watering.

See also: Backward Chaining

Freelance Work

Work done by a self-employed person who takes on tasks or projects for one or more clients rather than being an employee.

Example: A club hires a freelance designer to create the screens for its booking system.

Function

NESA

A term used in programming to describe a self-contained sequence of instructions that performs a specific task or tasks and is designed to be able to be reused throughout the program. System Flowchart

A diagram that represents the main processes and devices in a system, using symbols such as online input, direct access storage and cloud, with arrows showing the direction of data.

Example: A doctor's system where visit details are entered, stored in a consultation file and sent to the cloud.

System Implementation

NESA

The implementation method applied when introducing a new or redesigned enterprise system. Typically methods include: direct, parallel, phased or pilot.

Example: A club goes live with its stock module first and its booking module three weeks later.

System Maintenance

Work done after a system goes live to fix faults, adapt it to changes and improve it.

Example: Updating a booking system when the club adds a new membership type.

Systems Thinking

NESA

An understanding of how related objects or components interact to influence how systems function. Students are provided with opportunities to recognise the connectedness of, and interactions between phenomena, people, places and events in local and wider contexts and consider the impact of their decisions. Understanding the complexity of systems and the interdependence of components is important for scientific research and for the creation of solutions to technical, economic and social issues.

Example: Seeing that changing the canteen’s ordering app also affects the kitchen, the cashiers and the parents who pay.

T

Task Float

The number of days a task can be delayed without delaying the end date of the project; also called slack. Tasks on the critical path have no float.

Example: A task with 2 days of float can finish 2 days late and the project still ends on time.

See also: Critical Path, Gantt Chart

Threat Actor

NESA

An individual or group that poses a security threat to an individual or organisation.

Example: A criminal group running a ransomware campaign, or an employee who leaks customer data.

Transmission Media

NESA

The means through which data is sent from one system to another on a network.

Example: An Ethernet cable, an optical fibre or a Wi-Fi radio signal.

Trend Line

A line, usually the least-squares line of best fit, drawn through data to show its general direction and to make forecasts.

Example: A straight trend line fitted to twelve months of orders and extended one month ahead to forecast demand.

Truncated Axis

A value axis that does not start at zero, which can exaggerate differences in a column chart.

Example: A column axis from 90 to 95 makes 94% look four times as tall as 91%.

Trusted Platform Module (TPM)

A dedicated security chip that stores cryptographic keys in hardware and helps verify that a device started with trusted software.

Example: BitLocker uses a TPM to keep a laptop's drive encryption key safe.

Truth Maintenance

A technique that records the reasons for each conclusion so it can be withdrawn automatically when its supporting facts change.

Example: Retracting overwatered when the user corrects soil_wet to dry.

See also: Hypothetical Reasoning

U

Unstructured Data

Data with no predefined model or field layout, such as free text, images, audio and video.

Example: Rider comments, photos of damaged bikes and recorded customer calls.

See also: Structured Data

Unstructured Decision

A decision that cannot be made by following a fixed set of instructions, so human judgement is required. The syllabus describes it as "an infinite set of instructions where judgement may be required".

Example: Deciding whether a start-up should open a second shop in another town.

See also: Semi-structured Decision

User Experience (UX)

NESA

The usability, ease of use, and enjoyment provided in the interaction between the customer and the product.

Example: A checkout that takes three taps instead of ten.

See also: User Interface (UI)

User Interface (UI)

NESA

The means by which users interact with computer hardware or software. In software, this usually comprises fields for text and number entry, mouse pointers, buttons and other graphical elements. In hardware, switches, dials and light-emitting diodes (LEDs) provide information about the interactions between a user and a machine.

Example: The buttons, menus and text fields on a school canteen ordering page.

See also: User Experience (UX), Wireframe
↑ Back to Top
V

Validation

Checking that data is reasonable and allowed before it is accepted, for example by type, range, format or presence.

Example: A range check rejects an age of 250.

See also: Data Integrity, Verification

Vector Graphic

An image built from geometric shapes described by mathematical formulas, so it stays sharp at any size.

Example: A club logo saved as an SVG that prints equally well on a badge or a banner.

See also: Bitmap Graphic

Verification

Checking that data has been entered or transferred correctly, such as by double entry or comparing totals with the source.

Example: Two staff type the same figures and the system compares them.

See also: Validation

Version History

A record kept by a file or collaboration tool of who changed a file and when, allowing earlier versions to be restored.

Example: Restoring yesterday's version of a shared design document.

Virtual Reality (VR)

NESA

The use of computing technology to create a simulated environment. Unlike traditional user interfaces, VR places the user inside an experience. Instead of viewing a screen in front of them, users are immersed and able to interact with three-dimensional worlds.

Example: A headset that places you inside a 3D tour of a museum.

See also: Augmented Reality (AR)

Visualisation

NESA

The presentation of data or information through pictures or graphics to help the intended audience understand its significance.

Example: A column chart that shows monthly sales so a manager can see the busy months at a glance.

Volume Testing

Testing how a system performs with a large amount of data or many users.

Example: Loading ten thousand orders to check searches stay fast.

Vulnerability

A weakness in data, people, processes or technology that a threat actor can exploit.

Example: An internet-facing server that has not been patched.

W

Waterfall Approach

A development approach in which the stages (requirements, design, development, testing, installation and maintenance) run in order, each completed and signed off before the next begins. The syllabus calls it waterfall (structured).

Example: A hospital records system with fixed regulatory requirements is developed in signed-off stages.

See also: Agile Approach

Web Content Accessibility Guidelines (WCAG)

The W3C's internationally recognised guidelines for making web content accessible, organised under four principles: perceivable, operable, understandable and robust.

Example: Providing alt text for images and at least 4.5:1 contrast for body text.

Webometrics

The quantitative study of web resources, including the links between pages, their content and how they are used.

Example: Analysing which sites link to a page to estimate how relevant it is.

Weighted Graph

A graph in which each edge has a number, such as a distance, cost or delay.

Example: Cable lengths in metres on the links between five sites.

See also: Shortest Path

What-if Analysis

Changing an input to a model, such as a price or a quantity, to see how the results would change.

Example: Lowering the number of ham salad rolls put out each day to see the projected effect on waste and sales.

Wireframe

A simple, low-fidelity layout of a screen that shows structure and placement without colour or final content.

Example: Grey boxes labelled Header, Image and Button on a sketch of a home page.

See also: Prototype, Storyboard, User Interface (UI)

Workflow

NESA

A sequence of processes and/or activities that a document or artefact transitions through in order to reach completion.

Example: A leave request that moves from the employee to a manager for approval, then to payroll.
